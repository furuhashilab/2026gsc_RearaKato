# 離島におけるドローン物流の社会実装に向けた地理空間データ整備状況の分析
### ―新島・式根島を事例として―

**青山学院大学 地球社会共生学部／古橋研究室／2026年度ゼミ論**

> **執筆状況（2026年11月9日時点）**：IMRaD形式に整理した中間発表段階の研究草稿。OpenStreetMap（OSM）の5つの評価項目について初期調査を実施した。公開データの登録状況を対象とするものであり、実際のドローン運航の安全性やデータの網羅率は検証していない。

## Abstract（概要・暫定）

離島では、船便の欠航リスクや輸送コストなど、物流に関する課題が存在する。こうした課題への対応策としてドローン物流が注目されている。本研究では、東京都新島村の新島・式根島を対象に、ドローン物流に関連する公開地理空間データの整備状況を明らかにすることを目的とする。

OpenStreetMap（OSM）を中心に、建物の位置・高さ、道路網、港・ヘリポート等、電線・電柱・鉄塔、土地利用情報の5項目を調査し、Project PLATEAUの公開資料を補足的に確認した。

2026年11月9日時点の初期調査では、建物3,564 way、道路424 way、港・ヘリポート関連6件、土地利用86 wayが確認された。建物のうち高さタグが付与されていたのは391 way（10.97%）であり、指定した電力設備関連タグの登録は0件だった。

これらの結果から、公開地理空間データは情報の種類や属性によって登録状況が異なることが確認された。今後は、公開データから把握できる情報とその限界を整理する。

**キーワード：** ドローン物流、離島、OpenStreetMap、PLATEAU、地理空間データ、新島、式根島

---

## I. Introduction（研究背景・目的）

### 1.1 研究背景

離島では、船便の欠航リスクや輸送コストの高さなど、物流に関する課題が存在する。近年、こうした課題の解決策としてドローン物流が注目されており、国内各地で実証実験が進められている。

東京都新島村では、2025年6月にエアロセンス社が新島・式根島間でVTOL型ドローンの試験飛行を実施した。2026年度からの定期運航も計画されるなど、社会実装に向けた取り組みが進められている。

ドローンの安全な運用を検討する際には、地形や建物、障害物、離着陸地点などの地理空間情報が重要となる。

### 1.2 問題提起

OpenStreetMap（OSM）などの公開地理空間データは、ドローン物流に関連する情報の把握や共有に活用できる可能性がある。

しかし、対象地域において、ドローン物流に関連する情報がどの程度登録されているか、また、どのような情報を公開データから把握できないかを確認する必要がある。

特に、OSMにデータが登録されていないことと、現実世界に対象物が存在しないことは区別しなければならない。

### 1.3 リサーチクエスチョン（RQ）

> **RQ：新島・式根島において、ドローン物流に関連する公開地理空間データはどの程度整備されているか？**

### 1.4 研究目的

本研究では、新島・式根島を対象に、OpenStreetMap（OSM）を中心とした公開地理空間データについて、建物の位置・高さ、道路網、港・ヘリポート等、電線・電柱・鉄塔、土地利用情報の登録状況を調査する。

これにより、ドローン物流に関連する地理空間情報の整備状況を把握し、データの登録状況や情報が確認できない項目を明らかにすることを目的とする。

## II. Methods（研究方法）

### 2.1 対象地域

対象地域は、東京都新島村の新島・式根島とする。

初期調査では新島村の行政区域を検索対象とし、新島村全体の登録状況を集計する。島別の比較は本研究の必須項目としない。

### 2.2 使用データとツール

| データ・ツール | 用途 |
|---|---|
| OpenStreetMap（OSM） | 建物・道路・施設・電力設備・土地利用の登録状況の確認 |
| Overpass Turbo | OSMデータの検索と集計 |
| Project PLATEAU | 3D都市モデル等の公開状況の補足確認 |

OSMの検索には[Overpass Turbo](https://overpass-turbo.eu/)を使用した。PLATEAUについては、[新島村2024年度版3D都市モデル](https://www.geospatial.jp/ckan/dataset/plateau-13363-niijima-mura-2024)の公開資料を参照した。

### 2.3 評価項目

| 評価項目 | ドローン物流との関連 |
|---|---|
| 建物の位置・高さ | 周辺障害物の把握 |
| 道路網 | 地上配送・緊急時のアクセス確認 |
| 港・ヘリポート等 | 物流拠点・離着陸施設の把握 |
| 電線・電柱・鉄塔 | 飛行時の障害物の把握 |
| 土地利用情報 | 緊急着陸候補地の予備的な抽出 |

### 2.4 調査手順

2026年11月9日に、Overpass Turboを使用して新島村の行政区域内に登録されたOSMデータを検索した。

建物については`building`タグを持つwayの件数と、そのうち`height`タグが付与されたwayの件数を集計した。

道路については、主要な道路種別を表す`highway`タグを持つwayを集計した。

港・ヘリポート等については、`harbour`、`landuse=port`、`aeroway=helipad`、`aeroway=heliport`を検索した。

電力設備については、`power=line`、`power=minor_line`、`power=cable`、`power=tower`、`power=pole`を検索した。

土地利用については、`landuse`タグを持つオブジェクトを集計した。

### 2.5 評価範囲と制約

本研究では、公開データの登録件数と属性の有無を中心に評価する。

OSMの登録件数は、現実世界に存在する建物や施設の総数を表すものではない。また、データの登録状況から実際のドローン運航の安全性を判断することはできない。

## III. Results（結果：現時点の進捗）

> **注意：** 本節は2026年11月9日時点の初期調査結果である。現実世界に対するデータの網羅率や、ドローン物流への実運用上の適合性は検証していない。

### 3.1 OSMの登録状況

| 調査項目 | 件数 | 備考 |
|---|---:|---|
| 建物 | 3,564 way | `building`タグ |
| 高さタグ付き建物 | 391 way | `building`かつ`height`タグ |
| 道路網 | 424 way | 指定した道路種別 |
| 港・ヘリポート等 | 6件 | 港関連3件、ヘリパッド3件 |
| 電線・電柱・鉄塔等 | 0件 | 指定した5種類の`power`タグ |
| 土地利用 | 86 way | `landuse`タグ |

### 3.2 建物の位置・高さ

OSMに登録された建物wayは**3,564件**だった。

そのうち、`height`タグが付与されていた建物wayは**391件**であり、建物way全体に対する高さタグ付与率は**10.97%**だった。

高さタグが付与されていない建物wayは3,173件だった。

この割合はOSM内の建物wayを母数として算出したものであり、現実の建物に対する高さ情報の網羅率を示すものではない。

### 3.3 道路網

指定した`highway`タグに該当する道路wayは**424件**だった。

今回の調査では登録件数を確認したが、道路の総延長や現実の道路網に対する網羅率は算出していない。

### 3.4 港・ヘリポート等

港関連のOSMオブジェクトとして、次の3件を確認した。

- 新島港
- 式根島港
- 小浜漁港

また、`aeroway=helipad`に該当するオブジェクトを3件確認した。このうち1件には「式根島臨時ヘリポート」という名称が登録されていた。

港関連とヘリパッドを合わせて**6件**が確認された。

ただし、これらの施設がドローンの離着陸に利用可能かどうかは確認していない。

### 3.5 電線・電柱・鉄塔

指定した5種類の`power`タグを検索した結果、該当するOSMオブジェクトは**0件**だった。

また、今回確認した新島村2024年度版PLATEAUの公開データ収録一覧では、電線・電柱・鉄塔の専用モデルを確認できなかった。

ただし、これは現実に電線・電柱・鉄塔が存在しないことを示すものではない。

### 3.6 土地利用情報

`landuse`タグが付与されたOSMのwayは**86件**だった。

現時点では、土地利用の分類別件数や面積、地理的なカバー範囲は分析していない。

### 3.7 PLATEAUの公開状況

新島村2024年度版PLATEAUの公開READMEには、建築物LOD1モデルが**4,149棟**収録されていると記載されている。

道路や土地利用に関するデータも提供されている。

ただし、OSMとPLATEAUではデータの作成方法や対象の定義が異なるため、建物件数の単純比較による網羅率の算出は行わない。

---

## IV. Discussion（考察・暫定）

### 4.1 データの種類による登録状況の違い

今回の調査では、建物、道路、港・ヘリポート、土地利用に関するOSMデータの登録が確認された。

一方、電線・電柱・鉄塔については、指定したタグで該当データを確認できなかった。

このことから、ドローン物流に関連する情報であっても、データの種類によって登録状況が異なることが分かった。

### 4.2 建物の高さ属性の登録状況

建物wayは3,564件確認されたが、高さタグが付与されていたのは391件（10.97%）だった。

この結果から、OSMに登録された建物のうち、高さ属性を直接利用できるものは一部に限られることが分かった。

PLATEAUなどの別の公開データを補足的に利用することで、建物に関して把握できる情報が増える可能性がある。

### 4.3 公開データを利用する際の限界

今回の分析で確認したのは、公開データの登録状況である。

そのため、登録件数が多いことだけでデータの網羅性や正確性を判断することはできない。

また、港・ヘリポート等の位置情報が登録されていても、ドローン物流の拠点として利用できるとは限らない。

電力設備についても、今回の検索で登録が確認できなかったことと、現実世界に設備が存在しないことは区別する必要がある。

### 4.4 研究の意義

本研究は、新島・式根島を事例として、ドローン物流に関連する公開地理空間データから**把握できる情報と、把握できない情報を整理する**点に意義がある。

特に、建物の高さ属性の登録状況や、電線・電柱等の障害物情報を今回の検索条件では確認できなかった点は、今後のデータ整備を検討するための基礎資料となる。

---

## V. Conclusion（結論・暫定）

本研究では、新島・式根島を含む東京都新島村を対象に、ドローン物流に関連する公開地理空間データの初期調査を実施した。

OSMでは、建物、道路、港・ヘリポート、土地利用に関するデータの登録が確認された。一方、建物の高さタグ付与率は10.97%であり、指定した電力設備関連タグでは該当データを確認できなかった。

以上より、公開地理空間データには、情報の種類や属性によって登録状況に違いがあることが確認された。

今後は、調査条件と結果を整理し、ドローン物流の検討に関連する情報を公開データから把握する際の限界を明確にする。
