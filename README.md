# 研究構想①
# 離島におけるドローン物流の社会実装に向けた地理空間データ整備状況の分析
### ―新島・式根島を事例として―

## Introduction（序論）
### 研究背景
離島では、船便の欠航リスクや輸送コストの高さなど、物流に関する課題が存在する。近年、こうした課題の解決策としてドローン物流が注目されており、国内各地で実証実験が進められている。

東京都新島村では、2025年6月にエアロセンス社が新島・式根島間でVTOL型ドローンの試験飛行を実施した。2026年度からの定期運航も計画されるなど、社会実装に向けた取り組みが進められている。

ドローンの安全な運用には、地形や建物、障害物、離着陸地点などの地理空間情報が重要である。

### 問題提起
OpenStreetMap（OSM）などの公開地理空間データは、ドローン物流に関連する情報の把握や共有に活用できる可能性がある。

しかし、離島において、ドローン物流への活用という観点から公開地理空間データの整備状況を評価した研究は、十分に確認できていない。

### 研究目的・リサーチクエスチョン
**RQ：新島・式根島において、ドローン物流に関連する公開地理空間データはどの程度整備されているか？**

本研究では、新島・式根島のOSMデータを中心に整備状況を調査し、不足している情報や地域的な偏りを明らかにすることを目的とする。

## Methods（研究方法）
### 対象地域
東京都新島村の新島・式根島

### 使用データ
| データ | 用途 |
|---|---|
| OpenStreetMap | 建物・道路・施設・障害物の登録状況 |
| 国土地理院地図・基盤地図情報 | 地形・標高・建物位置等の参照 |
| PLATEAU | 建物3Dデータの公開状況確認 |
| 航空写真 | 地物の存在や位置の参考確認 |

### 分析手順
**1. OSMデータの取得**

Overpass Turboなどを使用し、両島の建物・道路・施設・障害物に関するデータを取得する。

**2. 評価項目の設定**

| 評価項目 | ドローン物流との関連 |
|---|---|
| 建物の位置・高さ | 周辺障害物の把握 |
| 道路網 | 地上配送・緊急時のアクセス確認 |
| 港・ヘリポート等 | 物流拠点・離着陸施設の把握 |
| 電線・鉄塔 | 飛行時の障害物の把握 |
| 土地利用情報 | 離着陸候補地の予備的な検討 |

**3. データ整備状況の評価**
- 建物や施設の登録件数
- 建物高さなどの属性情報の付与率
- 参照データとの比較
- 島ごとの整備状況の違い

**4. QGISによる可視化**

取得したデータをQGISで可視化し、整備状況の地域差や不足している情報を分析する。

## Results（想定される結果）
- 新島・式根島におけるOSMデータの整備状況を把握する。
- 建物・道路・施設等の属性情報の充足度を明らかにする。
- 両島のデータ整備状況を比較する。
- 不足している情報や地域を地図上に可視化する。

## Discussion（考察予定）
- 公開地理空間データは、ドローン物流に関連する情報の把握にどの程度活用できるか。
- ドローン物流を見据えた場合、どのようなデータが不足しているか。
- OSMマッピングによって不足する情報を補完できる可能性はあるか。
- 他の離島にも応用できる評価方法となるか。

なお、本研究では公開データの整備状況を評価するものであり、実際の飛行ルートや離着陸地点の安全性を判定するものではない。

### 研究の新規性
ドローン物流の社会実装が検討されている新島・式根島を対象に、公開地理空間データの整備状況を評価する点に特徴がある。

ドローン物流に関連する情報の充足度を定量的・空間的に分析し、今後のデータ整備に向けた課題を明らかにする。
