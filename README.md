青山学院大学 地球社会共生学部 古橋研究室

### 研究テーマの検討について

現在、ゼミ論の研究テーマとして、以下の2案を検討している。

1. **離島におけるドローン物流の社会実装に向けた地理空間データ整備状況の分析 ―新島・式根島を事例として―**
2. **横浜市の木造密集市街地におけるOSMデータ整備状況の評価 ―防災まちづくりへの活用可能性―**

研究の新規性、実現可能性、分析方法について比較し、今後の研究テーマを決定したい。

# 研究構想①
# 離島におけるドローン物流の社会実装に向けた地理空間データ整備状況の分析
### ―新島・式根島を事例として―

## Introduction（序論）
### 研究背景
離島では、船便の欠航リスクや輸送コストの高さなど、物流に関する課題が存在する。近年、こうした課題の解決策としてドローン物流が注目されており、国内各地で実証実験が進められている。

東京都新島村では、2025年6月にエアロセンス社が新島・式根島間でVTOL型ドローンの試験飛行を実施した。2026年度からの定期運航も計画されるなど、社会実装に向けた取り組みが進められている。

ドローンの安全な運用には、地形や建物、障害物、離着陸地点などの地理空間情報が重要である。

### 問題提起
OpenStreetMap（OSM）などの公開地理空間データは、ドローン物流に関連する情報の把握や共有に活用できる可能性がある。

しかし、離島において、ドローン物流への活用という観点から公開地理空間データの整備状況を評価した研究は、十分に確認できていない。

### 研究目的・リサーチクエスチョン
**RQ：新島・式根島において、ドローン物流に関連する公開地理空間データはどの程度整備されているか？**

本研究では、新島・式根島のOSMデータを中心に整備状況を調査し、不足している情報や地域的な偏りを明らかにすることを目的とする。

## Methods（研究方法）
### 対象地域
東京都新島村の新島・式根島

### 使用データ
| データ | 用途 |
|---|---|
| OpenStreetMap | 建物・道路・施設・障害物の登録状況 |
| 国土地理院地図・基盤地図情報 | 地形・標高・建物位置等の参照 |
| PLATEAU | 建物3Dデータの公開状況確認 |
| 航空写真 | 地物の存在や位置の参考確認 |

### 分析手順
**1. OSMデータの取得**

Overpass Turboなどを使用し、両島の建物・道路・施設・障害物に関するデータを取得する。

**2. 評価項目の設定**

| 評価項目 | ドローン物流との関連 |
|---|---|
| 建物の位置・高さ | 周辺障害物の把握 |
| 道路網 | 地上配送・緊急時のアクセス確認 |
| 港・ヘリポート等 | 物流拠点・離着陸施設の把握 |
| 電線・鉄塔 | 飛行時の障害物の把握 |
| 土地利用情報 | 離着陸候補地の予備的な検討 |

**3. データ整備状況の評価**
- 建物や施設の登録件数
- 建物高さなどの属性情報の付与率
- 参照データとの比較
- 島ごとの整備状況の違い

**4. QGISによる可視化**

取得したデータをQGISで可視化し、整備状況の地域差や不足している情報を分析する。

## Results（想定される結果）
- 新島・式根島におけるOSMデータの整備状況を把握する。
- 建物・道路・施設等の属性情報の充足度を明らかにする。
- 両島のデータ整備状況を比較する。
- 不足している情報や地域を地図上に可視化する。

## Discussion（考察予定）
- 公開地理空間データは、ドローン物流に関連する情報の把握にどの程度活用できるか。
- ドローン物流を見据えた場合、どのようなデータが不足しているか。
- OSMマッピングによって不足する情報を補完できる可能性はあるか。
- 他の離島にも応用できる評価方法となるか。

なお、本研究では公開データの整備状況を評価するものであり、実際の飛行ルートや離着陸地点の安全性を判定するものではない。

### 研究の新規性
ドローン物流の社会実装が検討されている新島・式根島を対象に、公開地理空間データの整備状況を評価する点に特徴がある。

ドローン物流に関連する情報の充足度を定量的・空間的に分析し、今後のデータ整備に向けた課題を明らかにする。

### 先行研究・参考資料

# 研究構想②
# 横浜市の木造密集市街地におけるOSMデータ整備状況の評価
### ―防災まちづくりへの活用可能性―

## Introduction（序論）
### 研究背景
横浜市には木造住宅が密集し、地震発生時の火災延焼や避難の困難さが懸念される地域が存在する。

こうした地域では、建物の位置や構造、道路幅員、避難場所などの地理空間情報を把握することが、防災まちづくりを進めるうえで重要である。

近年、市民参加型の地理空間データであるOpenStreetMap（OSM）は、防災や災害対応への活用が期待されている。

### 問題提起
OSMは自由に利用・編集できる一方、地域やデータ項目によって整備状況に差がある。

特に、木造密集市街地の防災対策に必要となる建物情報や道路幅員などが、OSM上でどの程度整備されているかについては、十分な検証が確認できていない。

そのため、既存の地理空間データと比較し、情報の充足度や不足項目を明らかにする必要がある。

### 研究目的・リサーチクエスチョン
**RQ：横浜市の木造密集市街地において、防災まちづくりに必要な地理空間情報はOSM上でどの程度整備されているか？**

本研究では、横浜市の木造密集市街地を対象に、OSMと既存の地理空間データを比較し、防災分野への活用可能性と課題を評価する。

## Methods（研究方法）
### 対象地域
横浜市が地震火災対策の対象としている木造密集市街地から、代表的な2〜3地区を選定する。


### 使用データ
| データ | 用途 |
|---|---|
| OpenStreetMap | 建物・道路・防災施設等の登録状況 |
| PLATEAU | 建物形状・高さ・用途等の参照 |
| 横浜市オープンデータ | 対象地区・防災施設等の確認 |
| 国土地理院地図・基盤地図情報 | 建物・道路・地形の参照 |

### 分析手順
**1. 対象地域の選定**

横浜市の公開資料をもとに、木造密集市街地から2〜3地区を選定する。

**2. OSMデータの取得**

Overpass Turboなどを使用し、建物・道路・避難場所・防災施設などのデータを取得する。

**3. 評価項目の設定**

| 評価項目 | 防災まちづくりとの関連 |
|---|---|
| 建物の位置・形状 | 建物密集状況の把握 |
| 建物用途・構造 | 木造建築物等の把握 |
| 道路幅員 | 避難・消防活動の検討 |
| 避難場所・防災施設 | 避難環境の把握 |
| 狭あい道路 | 避難・消防活動上の課題把握 |

**4. データ整備状況の定量評価**

OSMとPLATEAUなどの参照データを比較し、以下の指標を算出する。

- 建物データの登録率
- 建物属性情報の付与率
- 道路幅員情報の付与率
- 避難場所・防災施設の登録状況
- 地区ごとの整備状況の違い

比較にあたっては、データの取得時点や精度の違いを考慮する。

**5. 現地調査**

対象地区のうち1地区を訪問し、道路幅員や建物の状況、OSMに登録されていない地物などを確認する。

**6. QGISによる可視化**

データの登録状況や属性情報が不足している地域を地図上に可視化する。

## Results（想定される結果）
- 対象地区におけるOSMの建物・道路データ整備状況を把握する。
- 建物属性や道路幅員などの情報の充足率を明らかにする。
- 地区ごとのデータ整備状況を比較する。
- OSMとPLATEAUなどの参照データとの差異を把握する。
- 現地調査によってデータ不足の具体的な事例を確認する。

## Discussion（考察予定）
- OSMは防災まちづくりの基礎情報としてどの程度活用できるか。
- 地区によってデータ整備状況にどのような違いがあるか。
- 防災の観点から優先的に整備すべき情報は何か。
- 市民参加型マッピングによって不足する情報を補完できるか。

なお、公開データの充足度だけで実際の火災延焼リスクや避難の安全性を判断することはできない。

### 研究の新規性
横浜市の木造密集市街地に着目し、防災まちづくりに必要な地理空間情報の整備状況を定量的に評価する点に特徴がある。

OSMとPLATEAUなどの既存データを比較するとともに、現地調査による確認を行うことで、市民参加型地図データの活用可能性と課題を明らかにする。
