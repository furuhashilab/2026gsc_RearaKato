## 研究構想（IMRaD形式）

### 案①：離島 × ドローン物流
**[離島におけるドローン物流の社会実装に向けた地理空間データ整備状況の分析 ― 新島・式根島を事例として ―](island-drone-logistics.md)**

新島・式根島を対象に、OSM等の公開地理空間データがドローン物流に関連する情報をどの程度カバーしているかを評価する。

**RQ：** 新島・式根島において、ドローン物流に関連する公開地理空間データはどの程度整備され、どの情報に不足があるか？

### 案②：横浜市 × 防災
**[横浜市の木造密集市街地におけるOSMデータ整備状況の評価 ― 防災まちづくりへの活用可能性 ―](yokohama-disaster-osm.md)**

横浜市の木造密集市街地を対象に、防災に関連するOSMデータの整備状況を既存データや現地調査と比較する。

**RQ：** 横浜市の木造密集市街地において、防災まちづくりに関連する地理空間情報はOSM上でどの程度整備されているか？

## 2案の比較

| 観点 | 案① 離島ドローン物流 | 案② 横浜市防災 |
|---|---|---|
| 対象地域 | 新島・式根島 | 横浜市の木造密集市街地 |
| 主なデータ | OSM、国土地理院、PLATEAUの公開状況 | OSM、PLATEAU、横浜市オープンデータ |
| 分析 | 物流関連データの充足度・空間分布 | 防災関連データの充足度・地区比較 |
| 現地調査 | 必須とはしない | 1地区で実施予定 |
| 主な課題 | 運航に直結するデータ要件の整理 | 比較対象と評価指標の定義 |

## 今後の作業
1. ゼミ担当教員と研究テーマを相談し決定する。
